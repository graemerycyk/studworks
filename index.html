Why it is different

Your words become motion. Tell Studworks one thing you want your LEGO machine to do. It looks at the real hardware, creates a small program for the build in front of you, and shows you exactly what will run. If anything is unclear, it asks before it acts.

  • From idea to action. Describe what you want. Studworks creates the program; you decide when to run it.
  • It knows your build. Motors and sensors are matched to what is actually plugged in, so your train stays your train and your barrier stays your barrier.
  • Guardrails in every run. Movements have deadlines, motors coast when the program ends, and a jam is abandoned instead of forced.
  • Free forever. Private by design. No trial, account, API key or Studworks server. The app runs on your device, even offline.

Use with Claude or ChatGPT

Connection guide Connect your hub

For a cloud connection, start in Claude or ChatGPT using the guide. Its permission flow opens the hub page; opening that page on its own does not connect a chat.

Use Studworks on its own, or connect a compatible desktop AI app through Model Context Protocol (MCP). Explore your hardware, create a project and review its plan in Studworks before choosing to run it. The same app manages the Bluetooth connection and the execution limits.

One app. MCP included. The Mac app bundles the local MCP server. No source checkout, separate server installation, Studworks account or cloud setup. It is free, forever. Not a trial.

With the Mac app installed, open Studworks and choose Enable local MCP. In your AI app, add a local stdio MCP server pointing to:

/Applications/Studworks.app/Contents/Helpers/studworks-mcp

Keep Studworks open. Bluetooth permission belongs to Studworks, not the AI app. See the Claude, ChatGPT and terminal setup guide for manual connection steps and the upcoming browser connection.

Start with this read-only request:

> List nearby LEGO hubs. After I choose a hub, connect, run the non-moving self-test and inspect its ports. Do not move any motors.

An AI request is not permission to move: review each proposed run in Studworks and choose Approve and run or Decline.

The MCP server and Bluetooth connection run locally, but your chosen AI client may use its own service. Its plan, charges and privacy terms are separate from Studworks. Studworks itself remains free.

The Chrome web app and cloud MCP/public API are implemented and awaiting deployment and device checks. The web app uses our hosted service to plan and compile; a visible browser window connects to your hub. You do not need a Studworks account, and allowing a chat session never replaces approval of an exact run. How the browser connection works →
