Getting started / Connected apps

Use Studworks with Claude or ChatGPT.

Keep the conversation. Connect your LEGO machine.

7 September 2026 · Setup steps checked against provider documentation

Studworks gives a compatible assistant tools to understand your build, prepare projects and read results. You may see these connections called MCP servers, connectors or plugins. MCP is simply the shared language the apps use to work together.

Release status: the hosted connection and new Mac beta are being prepared. This guide covers manual setup for that release; Studworks is not yet an official directory integration. Cloud and real-hub checks still need completing.

Connect your hub Open Web App

Just want to build in Studworks? Open the web app. To connect a chat, start in Claude or ChatGPT using the steps below: opening the hub page alone does not authorize a chat session.

Claude · ChatGPT · Terminal tools · Hub permission

For Claude or ChatGPT in the browser

Use this deployment’s server address. It is a connection setting—not something to paste into your conversation:

https://studworks.build/mcp

You can plan without a hub. To use hardware, you also need a nearby compatible hub, Pybricks installed, and a desktop Chrome window connecting to it. Claude or ChatGPT cannot reach Bluetooth on your desk by itself.

Set up Claude

  1. Open Claude’s Customize → Connectors page. Choose +, then Add custom connector.
  2. Name it Studworks and enter the server address above.
  3. Choose the connector’s connection action and follow the permission screen. For hardware, continue with the hub steps below.
  4. In your conversation, enable Studworks through + → Connectors.

If you use a managed workspace, its owner may need to add the connector first. Menu labels and access can vary. See Claude’s current custom-connector instructions.

Set up ChatGPT

  1. In ChatGPT settings, open Security and login and enable Developer mode, if available.
  2. Open Plugins and choose +. Add the name Studworks and a short description such as “Plan and operate my LEGO builds”.
  3. Under Connection, enter the server address above. Create the connection and review the available tools.
  4. Use the connection’s authorization flow for hardware access, then add Studworks from the tools menu in a new conversation.

Developer mode can depend on your account and workspace policy. If it is missing, check OpenAI’s current manual connection guide; a website URL pasted into a chat does not install a connector.

Let your chat use this hub

  1. When the connection opens Studworks, keep that page visible in its own Chrome window.
  2. Choose Connect your hub and select your LEGO hub. Only continue if you started this connection; check the requesting app and return address.
  3. Review the requested access, tick the confirmation and choose Allow connection.
  4. Choose Return to your chat. Keep both windows visible. If your browser blocks the new window, allow pop-ups for Studworks and try again.

This grants temporary access for up to 30 minutes. It does not approve movement. The assistant can prepare a program or ask to run it; you check the exact program and choose Approve and run once beside the hub. The non-moving hub check needs its own local confirmation; any later motor test or program needs separate run approval.

Start with “Report the battery voltage.” Export projects you want to keep before closing the connection window: they stay only in memory here, not in the workbench’s saved project library. Hiding or closing the hub window ends access and sends a stop request. Keep the physical stop button within reach if the connection fails. Phone background control is not supported.

Claude Code or Codex on your Mac

For terminal tools, use the local connection bundled with the Studworks Mac app. It keeps Bluetooth in the app and does not need the browser window or the hosted service. Keep Studworks open in Applications and choose Enable local MCP under External AI / MCP.

With Claude Code installed, add the helper:

claude mcp add --transport stdio --scope user studworks -- /Applications/Studworks.app/Contents/Helpers/studworks-mcp

Use /mcp in Claude Code to check the connection. See Claude Code’s MCP guide.

With Codex installed, add the same helper:

codex mcp add studworks -- /Applications/Studworks.app/Contents/Helpers/studworks-mcp

Use codex mcp list to check it. OpenAI also documents adding local MCP servers through the desktop app’s settings. A local terminal configuration does not add the connection to ChatGPT on the web.

Keep the helper inside its matching Studworks app. If you installed it elsewhere, change the path. Use the app’s Copy MCP configuration for clients that accept JSON. Never paste passwords or access tokens into a conversation. Approvals still happen in Studworks, not in the terminal.

What leaves my device?

The browser connection sends project text, selected hub details and results through Studworks’ service and your chosen assistant. The local helper does not need Studworks’ cloud service, but your assistant may still process conversations online. Its subscription and privacy terms are separate. Studworks remains free, with no builder account to create.
