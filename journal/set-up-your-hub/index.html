Getting started / Hub setup

Set up your LEGO hub.

A little setup once. Then tell your machine what to do.

7 September 2026 · Studworks guide

Your hub is the small computer your LEGO motors and sensors plug into. Studworks connects to it over Bluetooth. You don’t need a special “Pybricks hub”—you need a compatible LEGO hub with Pybricks installed.

1. Check your hub

Studworks targets City Hub, Technic Hub, BOOST Move Hub, SPIKE Prime, SPIKE Essential and MINDSTORMS Robot Inventor. Older Power Functions battery boxes are not Bluetooth hubs. Check the Pybricks hardware and browser guide if you are unsure which you have.

For the browser connection, start with desktop Chrome and Bluetooth enabled. iPhone and iPad will use the native Studworks app, planned for later in September 2026, subject to Apple review; their browsers cannot provide this connection. A supported hub model does not mean every motor, sensor or project works in the current beta.

2. Give the hub the software it needs

Pybricks is alternative software for compatible LEGO hubs. It runs the programs Studworks prepares. If your hub already runs Pybricks, you can skip this step.

Installing it replaces the hub’s current software. Save any programs you want to keep, use charged batteries, and disconnect from Studworks or other LEGO apps before starting.

  1. Open Pybricks Code in its supported browser.
  2. Choose Tools → Install Pybricks Firmware, then select your hub model.
  3. Follow the installer’s instructions for that hub. Some hubs install over Bluetooth; SPIKE Prime, SPIKE Essential and Robot Inventor need a micro-USB cable.
  4. Wait for installation to finish, then disconnect from Pybricks Code.

The official installation guide includes hub-specific videos and recovery help. You can return to LEGO’s software using Tools → Restore official LEGO firmware. Studworks links you to this installer; its web connection page does not install firmware.

3. Connect in Studworks

Turn on your hub and make sure no other app is connected. Connect from Studworks, not your computer’s Bluetooth pairing settings.

  • In the web app: find Meet your hub, confirm it is stopped, then choose Choose a hub.
  • With Claude or ChatGPT: follow the connection guide. On the Studworks connection page, choose Connect your hub.
  • In the native app: choose Scan for hubs, select your hub and connect. Allow Bluetooth access for Studworks if asked.

If the hub does not appear, check that it finished installing Pybricks, is close by, and is disconnected from other apps. Use a fresh battery or charge it if necessary.

4. Check before your first run

Start with a clear test setup. The browser’s Run hub check and the native app’s Run no-motion self-test use the same non-moving check. Confirm it before continuing, then choose What’s plugged in? to identify the attached devices. The new guided setup takes you through these checks, a battery reading and a light test, asking whether you saw the expected result.

The guide’s optional motor test is separate: use a detached, unloaded motor, confirm its port, and review the 15° turn at 100°/s before approving it. The hub check itself does not move motors, and a completed program is not proof that the physical result happened.

Try “Report the battery voltage.” Review the proposed program before approving it. For movement, confirm which motor drives which part of your build and keep the hub’s stop button within reach. If a connection fails and you cannot confirm the motor stopped, use that physical button.

The hosted browser connection and new Mac beta are being prepared for release. Follow the availability on the download page; setup instructions are not a claim that every connection has completed hardware testing.
