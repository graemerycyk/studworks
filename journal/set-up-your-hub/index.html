Getting started / Hub setup

Set up your LEGO hub.

A little setup once. Then tell your machine what to do.

7 September 2026 · Studworks guide

Your hub is the small computer your LEGO motors and sensors plug into. Set it up once, then connect directly from the Studworks Web App.

1. Check your hub and browser

Studworks targets City Hub, Technic Hub, BOOST Move Hub, SPIKE Prime, SPIKE Essential and MINDSTORMS Robot Inventor. Older Power Functions battery boxes are not Bluetooth hubs. The Pybricks hardware guide helps identify your model.

Start with desktop Chrome and Bluetooth enabled. Other browsers can prepare a draft, but this beta needs direct browser Bluetooth to operate a hub. Support for more connection options is future work.

2. Install Pybricks if needed

Pybricks is the software on the hub that runs your Studworks programs. If it is already installed, skip to connecting.

Installation replaces the hub’s current software. Save programs you want to keep, use charged batteries and disconnect other apps first.

  1. Open Pybricks Code and choose its firmware installer.
  2. Select your hub model and follow the installer’s connection instructions.
  3. Wait for installation to finish, then disconnect from the installer and return to Studworks.

The official installation guide has model-specific instructions and recovery help. Studworks guides you to the installer; it does not install firmware itself.

3. Connect without leaving your build

Open the Web App. The connection window appears over your workspace. You can also open it using Connect hub in the header.

  1. Turn on your hub and check that no other app is connected.
  2. Choose whether Pybricks is installed. If you select Not yet or I’m not sure, follow the setup steps shown.
  3. Once ready, confirm the hub is stopped and the mechanism is clear. Choose Choose my hub and select it in the browser’s Bluetooth list.

If it is missing, check that Pybricks installation finished, the hub is close by, and it has power. Connect through Studworks, not your computer’s Bluetooth settings. You can choose Continue without a hub to write a draft first.

4. Start with something you can see

In Connected hardware, confirm your clear test setup and choose Run hub check. This check does not move motors. Then choose What’s plugged in? to identify the parts.

Try “Report the battery voltage.” Choose Make it, then Prepare this project. Review the program, confirm it is safe, and choose Run it. Look for the battery reading in the console.

Next try “Turn the hub light red.” Review and approve the new program, then check the actual light. Finishing a program does not prove the result happened.

Ready for movement? The small motor-move project explains a clear, unloaded setup and a separately approved turn. Keep the hub’s physical stop button within reach. If STOP is unconfirmed, use that button.

Using a chat assistant instead?

The Claude and ChatGPT guide explains the separate cloud connection. It still needs a nearby Bluetooth connection and approval of each exact run. You do not need that setup to build directly in the Web App.
