Getting started / Project files

What is a Pybricks project?

A LEGO program you can understand before you run it.

7 September 2026 · Studworks guide

First, what is Pybricks?

Pybricks is software for programming compatible LEGO hubs. Studworks uses it on the hub to run the programs you create in words. You don’t need to write Python to use Studworks. If your hub is new to this, start with hub setup.

What is in a project file?

A project file contains instructions for a build: which devices it uses and what they should do. Pybricks lets builders write Python or arrange visual coding blocks. Its program and file guide explains saving, exporting and viewing the Python behind blocks.

  • Python files (.py) contain readable code.
  • Block-project exports describe connected coding blocks, sometimes alongside Python text. The contents matter, not just the filename ending.
  • Studworks projects are different: they save your build’s intended behaviour, machine notes and versions. Use Make a shared project your own to open those.

What does “Check a Pybricks project” do?

Choose a file or paste its text, then select Inspect without running. Studworks looks for devices, motor actions, sensor use and patterns it cannot safely understand. This is a read-only inspection: it does not download the file to a hub or execute its code.

In the web workbench, selecting a file only loads it into the page. Choosing to inspect sends its contents to the Studworks service. Only inspect files you are comfortable sending. The native app performs its inspection locally.

Can I run any file I find?

No. A program written for another machine might start the wrong motor, turn continuously or depend on a sensor you don’t have. A successful inspection is not a safety certificate.

Block graphs are currently inspection-only. Python inside a block file must be reviewed separately; Studworks does not assume it matches the blocks. Supported Python can be translated through the native app’s guarded import workflow, but unsupported code is refused. A ZIP backup or binary project cannot be read as a plain text file; export the individual program instead.

To try an idea from someone else’s build, describe it in your own words or open a shared Studworks project. You’ll still connect your own hub, confirm the devices and approve a fresh program before anything runs.
