Getting started / Project files

What is a Pybricks project?

A LEGO program you can understand before you run it.

7 September 2026 · Studworks guide

First, what is Pybricks?

Pybricks is software for programming compatible LEGO hubs. Studworks uses it on the hub to run programs you create in words. You do not need to write Python. Start with hub setup if this is new to you.

What is in a project file?

A project describes instructions for a build: devices, actions and conditions. Pybricks supports Python and visual coding blocks. Its program and file guide explains saving and exporting them.

  • Python files (.py) contain readable program text.
  • Block-project exports describe connected coding blocks, sometimes alongside Python. The contents matter, not just the filename.
  • Studworks backups describe a build’s intended behaviour, machine details and retained versions. They are not the same format as a Pybricks program.

Understanding a file is different from running it

Read-only inspection can identify devices, motor actions and unsupported patterns without sending a program to a hub. It must never execute a file simply to discover what it does.

The focused Studworks Web App starts with your instruction rather than importing another program. File inspection and shared-project import are retained as future interface work, not launch controls.

Can I run any file I find?

No. Another machine’s program might start the wrong motor, run continuously or depend on a missing sensor. A successful inspection is not a safety certificate. Python embedded in a block file cannot be assumed to match its blocks, and a binary archive is not a plain-text program.

To try a project idea, describe the desired behaviour in your own words. Check your own devices and review a fresh program before approving it. Browse project notes for a place to start.
